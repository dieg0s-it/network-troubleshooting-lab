# Network Troubleshooting Lab

## Overview

This repository documents my practical learning journey in IT support and network troubleshooting.

The objective is to develop hands-on experience with fundamental networking technologies, diagnostic tools, and incident management procedures.

These labs complement my professional experience in technical support, customer service, incident management, and IT support training.

## Learning Objectives

- Understand DNS resolution and troubleshoot common DNS issues.
- Investigate basic HTTP and HTTPS connectivity problems.
- Use command-line tools to diagnose network connectivity.
- Develop structured troubleshooting methodologies.
- Document technical incidents and escalation procedures.

## Lab Environment

- Operating System: Ubuntu Linux
- Tools: `dig`, `nslookup`, `curl`, `ping`, `tracepath`
- Documentation: Markdown
- Platform: GitHub

## Labs

### 01 — DNS Troubleshooting
Investigating DNS resolution, DNS records, and common name resolution issues.

### 02 — HTTP/HTTPS Troubleshooting
Understanding HTTP requests, response codes, and basic HTTPS connectivity diagnostics.

### 03 — Network Diagnostics
Using basic network diagnostic tools to investigate connectivity and routing problems.

### 04 — Incident Documentation
Creating structured technical incident reports, including troubleshooting steps, findings, and escalation notes.

## About Me

I have over 20 years of professional experience in administrative operations, customer support, technical assistance, and incident management.

I am currently developing my technical skills through Google IT Support and Cisco training, while preparing for the CompTIA Network+ certification.

This repository represents my commitment to continuous learning and practical technical development.
